
## Как подставить в панель зала

В `ClubScene.tsx` вверху:

```tsx
import ArtIcon from './components/ArtIcon';
```

Дальше меняешь эмодзи на компонент. Было:

```tsx
<button onClick={p.onExit}>🚪</button>
```

Стало:

```tsx
<ArtIcon name="exit" size={44} onClick={p.onExit} title="Выход" />
```

Так же по всей панели: `decor`, `group`, `sound_on` / `sound_off`, `clap`,
`edit`, `settings`, `help`, `idea`, `like`.

Значок «ТОП КЛУБА» — `<ArtIcon name="top_club" size={56} />`.
Замок на закрытом зале — `<ArtIcon name="lock" size={32} dim />`.
Ежедневная награда — `<ArtIcon name="gift" size={72} glow />`.

## Звания

В `ClubberAvatar.tsx` вместо короны-эмодзи над аватаркой:

```tsx
import ArtIcon from './ArtIcon';
import { TITLE_ART } from '../config/art';

{clubber.title && (
  <ArtIcon name={TITLE_ART[clubber.title]} size={22} className="title-badge" />
)}
```

## Важно

Если картинка не найдётся, `ArtIcon` сам покажет эмодзи. Игра не сломается,
пока остальные арты не готовы.
