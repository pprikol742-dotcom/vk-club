# Музыка: только за пультом, только по «Зарядить»

Три файла заменяются целиком:

    src/lib/music.ts
    src/features/room/useClubMusic.ts
    src/features/room/ClubRoom.tsx

## Что изменилось

- `ClubPlayer` больше не стартует сам. Есть `start()` — единственная точка
  запуска, и `stop()`, который снимает src, чтобы звук не ожил.
- `unlock()` теперь ничего не проигрывает: он только берёт у браузера
  разрешение на будущее. Раньше он запускал трек от любого тычка по залу.
- `useClubMusic` принимает третьим аргументом `myVkId` и сам считает
  `atBooth`. Если ты не за пультом — звука нет вообще.
- Ушёл с пульта, перекупили, трек сняли, вышел из зала — стоп автоматом.
- В панели зала появилась кнопка «Зарядить» (▶). Видна только диджею и
  только когда трек выбран. После зарядки меняется на «Снять с пульта» (⏹).
- Полоса трека у слушателей считается от времени старта на сервере:
  видят движение, но не слышат.
