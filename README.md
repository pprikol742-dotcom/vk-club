# VK Клуб (диджей-симулятор) — Этап 1

Каркас проекта: авторизация через VK, создание клуба из своего паблика,
базовая комната с DJ, чатом, подарками, ежедневной наградой, светомузыкой
и заготовкой под перекуп ("Гарем").

Стек: React + TypeScript + Vite 5.4.11 + Zustand + Supabase (Postgres +
Realtime + Edge Functions) + `@vkontakte/vk-bridge`.

## Что уже готово в этом этапе

- VK Bridge init + проверка подписи launch-параметров (`verify-launch`) — без
  этого никто не подделает свой vk_id.
- Создание клуба из паблика, где ты руководитель (`create-club`, проверка
  через `groups.getMembers`).
- Комната клуба: DJ-стойка, кнопка «Стать DJ», лайки/дизлайки трека,
  подарки диджею (+ Сигара) и игрокам (+ Мороженое, + Шоколадная конфета),
  чат в реальном времени.
- Личная светомузыка — кнопка 💡 в верхней панели, включается/выключается
  индивидуально, видна всем через Presence-канал.
- «Резонанс зала» (моя добавка) — вспышка на весь экран, когда трек набирает
  много лайков подряд без дизлайков.
- Ежедневная награда: 1 → 7 монет по нарастающей, цикл 7 дней, сброс при
  пропуске дня.
- Заготовка «Гарем» / перекуп (`harem-buyout`) — есть в схеме и в edge
  function, экрана в UI пока нет (следующий этап).
- Неоновая палитра вместо фиолетовой — `src/styles/theme.css`.
- Живые эффекты подарков: сигара/кальян дымят, кофе/чифир парят, пиво летит
  к DJ-пульту, открывается и роняет пробку рядом — `GiftFxLayer.tsx` +
  анимации в `theme.css`. Любой подарок автоматически исчезает из комнаты
  не позже чем через 60 секунд после отправки (запись в БД для топа щедрых
  при этом остаётся).
- Аватар слегка танцует (покачивается), пока в клубе есть активный DJ.
- Магазин рук — рабочий экран (`HandSkinShop.tsx`): 8 рук (Рокер, Леди,
  Мужик, Д. Вейдер, 2 варианта Зомби, Киберпанк, Арестант), покупка списывает
  монеты один раз, дальше переключение между уже купленными — бесплатно.
  Экипированная рука видна бейджем над аватаркой на танцполе. Картинки лежат
  в `public/assets/hands/`.
- «Вечный топ» клуба — `is_featured` на клубе `vk.ru/club241178960` выставляется
  автоматически при создании (список ID зашит в `create-club/index.ts`,
  `FEATURED_GROUP_IDS`). Пока нет экрана списка клубов — сортировка по этому
  полю подключится на Этапе 2.
- Статус «Основатель» — первые три уникальных игрока, когда-либо
  зарегистрировавшиеся в игре (не в конкретном клубе), получают
  `founder_rank` 1/2/3 и медаль 🥇🥈🥉 рядом с монетами. Выдаётся атомарно
  через `game_counters` + `upsert_profile_with_founder()`, гонки при
  одновременной регистрации исключены.

## Что нужно сделать перед первым запуском

1. **VK Mini App** и **Supabase** — уже настроены, ключи лежат в `.env`
   (файл в архиве, в git не попадёт — `.gitignore` уже правит это).

2. **Применить схему в Supabase**:
   ```bash
   npx supabase init
   npx supabase link --project-ref sghgkhljvgrvhmmkihkh
   npx supabase db push          # применит supabase/migrations/*.sql
   npx supabase functions deploy verify-launch create-club claim-daily-reward \
     dj-action gift-action harem-buyout send-chat-message
   npx supabase secrets set VK_CLIENT_SECRET=2xfTdCipnozaf1i4N2bG
   npx supabase secrets set VK_SERVICE_TOKEN=44172c5b44172c5b44172c5ba84754702f0441744172c5b2e82753e2ec99151734e4b0d
   ```
   (`SUPABASE_SERVICE_ROLE_KEY` для функций Supabase подставляет сама —
   вручную задавать не нужно.)

   Важно: сама схема лежит в `supabase/migrations/20260831000000_init.sql`.
   Команда `db push` смотрит только на папку `migrations/`, файл
   `supabase/schema.sql` — просто человекочитаемая копия для гита, CLI её
   не трогает. Если увидишь "Remote database is up to date" сразу после
   `link`, а таблиц в Table Editor нет — значит миграция не легла, проверь,
   что файл действительно в `supabase/migrations/`.

3. Включить Realtime для таблиц `club_sessions`, `chat_messages`, `gift_transactions`
   в Supabase Dashboard → Database → Replication (без этого дым/пар/пиво и
   вспышка «Резонанс зала» просто не будут прилетать другим игрокам).

4. `npm run dev`, открыть через VK туннель (`npx vk-tunnel` или ngrok) и
   указать полученный https-адрес в настройках приложения на vk.com
   (App ID 54746228).

5. Убедись, что ты числишься руководителем в `vk.ru/club241178960` —
   иначе `create-club` откажет при попытке создать клуб из этого паблика.

> Важно: `.env` и секреты Supabase — не публикуй репозиторий с этими
> файлами. Если решишь выложить код на GitHub — делай приватным (как
> у тебя заведено для «Свои»).

## Ограничение по музыке (важно)

`audio.get` закрыт ВКонтакте для сторонних приложений с 2016 года.
Плейлист «из своей музыки в VK» напрямую не тянется. В схеме уже заложено
поле `track_source: 'user_upload' | 'library'` — на следующем этапе делаем
загрузку своего mp3-файла как основной путь.
